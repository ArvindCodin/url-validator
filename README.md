# URL Validation Using Regular Expressions

Theory of Computation (SCSB1303) project, Team 7. A static site with a live validator, finite-state view, baseline comparison, test suite and ReDoS test.

## Deploy on Vercel
1. Push these files to the root of a GitHub repo.
2. In Vercel, choose Add New > Project and import the repo.
3. Leave Framework Preset as "Other" with no build command, then Deploy.

## Run locally
Open `index.html` in a browser, or run `npx serve`.
